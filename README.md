# ⚡ ACCelerate'26 — QR Check-In System

A production-ready QR-Based Participant Check-In / Check-Out System built for ACCelerate'26 Tech Week.

## 🔗 Live Demo
👉 [https://unnati-chouksey.github.io/accelerate26](https://unnati-chouksey.github.io/accelerate26)

## 🚀 Features
- 📝 Participant Registration with all form fields
- 🎫 QR Code Generation (auto after registration)
- 📷 Camera-based QR Scanner
- ✅ Check-In / Check-Out system
- 🗓 3-Day attendance tracking
- 📊 Live Admin Dashboard
- 📋 Scan Logs with filters
- ⬇ Export attendance as CSV

## 🛠 Tech Stack
- HTML5, CSS3, JavaScript
- Supabase PostgreSQL (Database)
- GitHub Pages (Hosting)
- QRCode.js + Html5-Qrcode
